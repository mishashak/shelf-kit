# tools

## check-doc.mjs

문서 규약 중 **기계가 판정할 수 있는 것만** 검사합니다. 의존성이 없고 Node 18 이상에서 돕니다.

```bash
node tools/check-doc.mjs <파일 또는 폴더> [...]
node tools/check-doc.mjs --list      # 무엇을 검사하는지 보여줍니다
```

오류가 하나라도 있으면 종료코드 1을 냅니다. 커밋 훅이나 빌드 단계에 걸 수 있습니다.

### 검사하는 것

| 규칙 | 무엇을 |
|---|---|
| `glyph-emdash`, `glyph-middot` | 엠대시와 가운뎃점을 장식으로 쓴 자리 |
| `glyph-roman` | 로마숫자 소제목 |
| `plain-ending` | 평서체 종결 (보고 문서만 대상) |
| `deck-reveal` | 덱으로 보이는데 Reveal 골격이 아닌 것 |
| `self-contained` | 단일 HTML의 상대참조와 외부 자원 참조 |
| `details-print` | 접기가 있는데 인쇄 처방이 없는 것 |
| `details-label` | "더 보기" 같은 무의미한 접기 라벨 |
| `anchor-base-guard` | 문서 내 앵커에 뷰어 대비 처방이 없는 것 |
| `fit-guard` | 자동 화면맞춤 회피에 `translateZ(0)`을 쓴 것 |
| `font-abs-path` | `@font-face`가 상대경로인 것 |
| `keep-all-minwidth` | `keep-all`과 flex/grid를 함께 쓰며 `min-width: 0`이 없는 것 |
| `color-name-in-copy` | "빨간 막대" 처럼 색 이름을 문구에 박은 것 |
| `placeholder` | `TODO`, `TBD` 같은 미완성 표식 |
| `filename` | 파일명의 "최종", "final" 류 즉흥 접미사 |

### 검사에서 빼는 것

- **인용 구역**: 코드블록, 인라인 코드, URL, HTML 주석은 표기 검사 전에 지웁니다. 원어 제목이나
  코드 안의 기호는 우리 문장이 아닙니다. **무엇을 왜 뺐는지 실행할 때 세어 출력합니다.** 조용히
  빼면 다음 사람이 규칙이 없는 줄 압니다.
- **글리프를 이름으로 부르는 자리**: "엠대시(—)를 쓰지 않습니다" 같은 문장은 위반이 아닙니다.
- **도구 문서의 말투**: 설치 안내와 에이전트 절차서, 저장소 README는 평서체가 관용이라 말투
  규칙에서 뺍니다. 표기 규칙은 그대로 적용됩니다.

### 검사하지 않는 것

독자 레지스터, 서사 아크, 미감, 사실 정확성입니다. **이 도구가 통과했다는 것은 규약을 지켰다는
뜻이 아니라 기계가 잡는 하자가 없다는 뜻입니다.** 사람 눈이 볼 것은 각 규약 문서 끝의 체크리스트로
봅니다.
