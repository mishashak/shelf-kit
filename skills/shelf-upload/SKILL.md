# 꽂이(shelf) 업로드

이 스킬 폴더의 `scripts/upload.mjs`로 문서를 꽂이에 올린다. 인증은 개인 API 토큰(환경변수 `SHELF_URL`/`SHELF_TOKEN` 또는 홈 폴더의 `.shelf-upload.json`)이며, 없으면 스크립트가 안내 메시지를 내니 그대로 사용자에게 전달한다(토큰은 꽂이 웹 → 계정 설정 → API 토큰에서 발급).

## 절차

1. **올릴 파일 확정**: 지원 형식은 네 가지.
   - `.html` 단일 파일: 이미지와 CSS가 전부 인라인이어야 한다(상대참조가 있으면 서버가 거부).
   - `.zip`: 루트에 `index.html`이 오도록 묶는다. 폴더째 올려달라고 하면 먼저 zip으로 압축한다(PowerShell이면 `Compress-Archive -Path <폴더>\* -DestinationPath out.zip`, 폴더 안 내용물 기준으로 묶어야 index.html이 루트에 온다).
   - `.md`: 회의록과 메모. 서버가 읽기용 HTML로 구워서 올린다.
   - `.pdf`: 원문을 그대로 보관하고 서버가 pdf.js 뷰어를 씌워 올린다. 내보내기도 원본을 그대로 준다.

2. **규격을 서버에서 받아온다**: 채울 필드와 고를 수 있는 값은 **여기 적지 않는다. 서버가 정본이다.**
   ```
   node <스킬폴더>/scripts/upload.mjs --schema
   node <스킬폴더>/scripts/upload.mjs --schema --space report   # 그 선반에서 쓰는 태그만 추려서
   ```
   응답의 `fields`(무엇을 채우나), `vocabulary`(고를 수 있는 값), `notes`(주의)를 읽고 정한다.
   선반과 태그와 언어는 계속 늘어나므로 **기억해 둔 값을 쓰지 말고 올릴 때마다 이걸 본다.**

3. **메타데이터 정하기**: 규격을 읽은 뒤 모르는 것만 사용자에게 짧게 확인한다. 특히 셋은 빠뜨리지 않는다.
   - **태그**: 기존 어휘에서 고른다. 유형 1~2개에 제품이나 프로젝트 1개가 관행이다. 마땅한 게 없을 때만 `--tag-custom`으로 새로 만들고, 그때는 사용자에게 먼저 확인한다.
   - **열람 범위**: 안 보내면 가장 좁게 잠긴다(올린 사람과 관리자만 보임). 팀이 봐야 하는 문서면 **누가 봐야 하는지 사용자에게 확인해서** `--viewers "a@…,b@…"`로 지정하거나, 사내 전체가 봐도 되는 내용이면 `--visibility internal`로 넓힌다. 후보 계정은 규격의 `vocabulary.people`에 있다. **추측해서 넓히지 않는다.**
   - **날짜와 참석자**: 규격에서 그 선반의 `wantsDate`, `wantsPeople`이 켜져 있으면 반드시 챙긴다.

4. **실행**
   ```
   node <스킬폴더>/scripts/upload.mjs 파일.html --title "제목" --space deck --slug english-slug --tags "태그1,태그2"
   ```
   스크립트가 올리기 전에 규격을 한 번 받아 값을 검사한다. 모르는 선반이나 언어면 멈추고 고를 수 있는 값을 보여 주고, 태그가 비었거나 그 선반이 요구하는 항목이 빠졌으면 경고를 낸다.

5. **결과 보고**: 성공 시 출력되는 문서 URL을 사용자에게 그대로 전달한다. 실패 메시지도 요약하지 말고 원문을 보여준다. 좁은 범위로 올렸다면 "팀이 보려면 웹 화면에서 열람자를 지정해야 한다"고 함께 알린다.

## 규칙

- **같은 문서의 새 판은 새 문서로 올리지 않는다.** 서버가 같은 문서로 의심되면 409로 막고 후보를 돌려주며,
  이 스크립트는 그 후보의 새 버전으로 자동 교체한다(버전은 서버가 올린다). 새로 만들면 요약과 열람자와 조회 기록이
  옛 문서에 남고 새 문서는 빈 채로 출발한다, 실제로 같은 보고서가 두 벌 남은 적이 있다(2026-07-31).
  정말 별개 문서일 때만 `--new`를 붙인다.
- 파일을 만들기 전에 미리 알고 싶으면 `GET /api/docs/similar?title=<제목>`으로 물어본다.
- `--slug`는 **영문 소문자와 숫자, 하이픈**으로 명시한다. 한글 슬러그는 URL과 저장소 도구에서 깨진다.
- 버전은 semver(`v0.1.0` 시작)로 명시한다. 파일명이 `프로젝트_문서성격_YYMMDD_v0.0.0` 꼴이면 그 버전을 그대로 쓴다.
- AI가 올렸다는 표기(🤖)가 기본으로 붙는다. 사용자가 직접 만든 문서를 대신 올려주는 경우에는 `--no-ai`를 붙인다.
- 선반과 태그는 열람 권한과 무관하다. 권한은 열람 범위와 문서별 열람자 지정으로만 정해진다.
